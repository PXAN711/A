# 换三张 · 局域网四人麻将（四川血战到底）

一个无需公网、同机房（同一局域网）就能 4 人联机的麻将网页。一台电脑当主机启动，
其余朋友用浏览器访问主机 IP 即可入座。固定一桌、进房先建 ID、每人初始 50 豆。

## 一、怎么启动（主机这台电脑）

### 方式 A：双击启动（推荐）
直接双击 **`启动游戏.bat`**。首次会自动安装依赖，之后会显示类似：

```
本机打开:        http://localhost:3000
同机房朋友打开:  http://192.168.x.x:3000
```

### 方式 B：命令行
```bash
npm install        # 仅第一次
npm start
```

> 需要先装 Node.js（已检测到你本机是 v22，可直接用）。

## 二、同机房朋友怎么进来

1. 主机和朋友电脑连**同一个机房网络 / 同一个交换机 / 同一个 WiFi**（同一网段）。
2. 主机双击启动后，看窗口里 `同机房朋友打开: http://192.168.x.x:3000` 这一行。
3. 朋友在自己电脑浏览器打开这个地址（主机自己开 `http://localhost:3000`）。
4. 各自输入 ID 昵称入座，4 人都点**准备**即自动开局。

### 朋友打不开？99% 是防火墙
- 主机首次启动时 Windows 会弹"是否允许 Node.js 通信"，**勾选"专用网络"并点允许**。
- 若没弹窗或被拦：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 →
  新建规则 → 端口 → TCP → 特定端口 `3000` → 允许连接。
- 确认两台机互相 ping 得通；机房若做了客户端隔离，需找网管放开同网段互访。

## 三、规则口径

- **用牌**：万/条/筒共 108 张，无字牌无花牌；4 人，不许吃，只能碰/杠/胡。
- **换三张**：开局每人选 **3 张同花色**换出；掷两颗骰子看点数和定方向（全场统一）：
  - 点数和**能被 4 整除（4/8/12）→ 给下家**
  - 点数和为**单数（3/5/7/9/11）→ 给对家**
  - **其余双数（2/6/10）→ 给上家**
  - **换撞重开**：若四家换出的牌恰好是同一花色（全万/全条/全筒），本局不作数、不扣豆，庄家不变重新发牌再换。
- **定缺**：换完后每人选一门缺，缺门没打干净之前不能胡、也不能碰/杠；胡牌时手里不能有缺门牌。
- **血战到底**：一家胡了不结束，胡的人离场，其余继续，直到 3 家胡或牌墙摸完。
- **番型倍数**（多个番型相乘）：
  | 番型 | 倍数 |
  |---|---|
  | 平胡 | ×1 |
  | 对对胡 | ×4 |
  | 清一色 | ×6 |
  | 七对 | ×6 |
  | 清对（清一色+对对胡） | ×24 |
  | 清一色七对 | ×36 |
  （已按要求**去掉金钩钓、根**；不封顶；平胡可点炮。）
- **杠（刮风下雨，当场结算，底注 1 豆）**：暗杠其余三家各付 2；明杠（点杠）出牌者付 2；补杠（巴杠）其余三家各付 1；补杠可被**抢杠胡**。
- **结算**：自摸由当时所有未胡者各付；点炮由放炮者一人付；一张牌点多家=一炮多响，分别赔付。
- **流局**：查花猪（手里还留缺门牌，赔其余每人 6 豆）、查叫（没听牌的赔听牌者其最大可胡番型）。
- 豆子跨局累计；断线由系统自动托管（自动换牌/定缺/出牌/过），用**同一个 ID** 刷新页面可回到座位。

## 四、操作说明

- **换三张阶段**：点选手牌（3 张须同花色，被选中会抬起金边）→「确认换出」。
- **定缺阶段**：点「定缺 万/条/筒」。
- **你的回合**：点一张牌 →「出牌」（或双击直接出）；能自摸会出现「自摸胡」；能暗杠/补杠会出现对应按钮。
- **别人出牌**：你能碰/杠/胡时，屏幕中央会弹出窗口，分别给出「胡/不胡」「杠/不杠」「碰/不碰」按钮；点对应操作即插队先结算，其他家仍可抢胡（一炮多响）。10 秒不操作自动放弃。
- 自己回合 25 秒不出牌会自动出（优先出缺门牌），防止有人卡住整桌。
- **牌桌**：四家正方形围坐，自己在南（下方）、对家在北、上家在东（左）、下家在西（右）；左右两家的手牌按现实麻将竖直立在两侧。中盘显示东南西北方位、骰子点数与换牌方向、牌墙剩余。
- **聊天**：右上角「牌桌聊天」小窗，输入回车发送；点标题可收起/展开，不挡牌面。

## 五、想改配置

打开 `server.js` 顶部：
- `PORT` 端口；`START_BEANS` 初始豆子；`BASE` 底注；`TIME` 各阶段超时秒数；`HUA_PENALTY` 花猪赔付倍数。
- 番型倍数在 `game/rule.js` 的 `calcFan()` 里改。
